Environment setup (Windows). Run in COMMAND PROMPT (Start, type cmd, Enter), NOT PowerShell.
One block per topic. Start the installs first, one window per topic (5 to 15 min each).
Success check: after the activate line you see (gan) / (imggen) / (music) / (detect) at the start of the line.
In Jupyter: New, then Python (<topic name>). Next time: run only the activate line + the last line.
Check first: py -3.13 --version  (if 'py' not found, use 'python' instead of 'py -3.13')

==================== GAN (TensorFlow) ====================
py -3.13 -m venv C:\dl\gan
C:\dl\gan\Scripts\activate
python -m pip install --upgrade pip
pip install tensorflow==2.21.0 keras==3.15.1 matplotlib notebook ipykernel ipywidgets
python -m ipykernel install --sys-prefix --name gan --display-name "Python (gan)"
pip check
jupyter notebook --notebook-dir=C:\dl
